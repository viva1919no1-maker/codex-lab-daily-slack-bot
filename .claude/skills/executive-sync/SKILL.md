# Executive Sync（取締役同士の連携効率化）

出典: Claude Code活用法50選のうち「メール・Slack連携」「上級者の使い方」カテゴリをviva事業の取締役連携向けに適用したもの。

## できること

### 1. 連絡のトリアージ
- Slack/メールの未読・スレッドを重要度別に振り分ける
- 返信が必要なものだけ抽出する
- 「至急」を含むものを最優先で並べる
- 出力は「結論→根拠→次アクション」で各取締役向けに簡潔にまとめる

### 2. 議事録からタスク抽出
- 会議の文字起こし・議事録を読み込み、取締役ごとの担当タスクだけを抜き出す
- 担当者・期限を明示してリスト化し、抜け漏れがないか確認する

### 3. 意思決定の並列検証
- 判断が割れそうな論点は、Agent toolで複数の視点（例: 財務リスク重視／成長速度重視／現場負荷重視）を担当する別エージェントを立てて同時に検証する
- 各視点の結論を比較表にして提示し、最終判断はオーナー・取締役に委ねる
- 検証エージェントには検討の経緯を渡さず、結論だけを文脈なしで評価させる（書く人とチェックする人を分けて自己採点の甘さを避ける）

### 4. 定例レポートの自動化
- 週次のKPI・進捗をテンプレートに流し込み、取締役全員が同じフォーマットの報告をSlackで受け取れるようにする
- 同じ集計を2回以上繰り返したら、その場で終わらせずカスタムコマンド化を提案する

## 運用ルール
- いきなり全件処理しない。まず候補一覧・トリアージ結果を出し、承認を経てから次のアクションに進む。
- Slackへの送信は `mcp__Slack__slack_send_message`（即時）または `slack_schedule_message`（定刻配信）を使う。
- 重要な決定の比較結果は埋もれないよう、該当チャンネルにスレッドでまとめて投稿する。
